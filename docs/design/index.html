01 — Foundations

Brand & Design Principles

RISE is an AI Interview Coach. The interface must feel like a calm, supportive partner — never a complex technical tool — because many users arrive with interview-related anxiety. The style is Modern Corporate Minimalism: high legibility, intentional white space, and precise alignment that keep all focus on the student's performance and the AI's feedback.

Personality

  • Authoritative — trustworthy guidance, grounded in a professional blue.
  • Supportive — encouraging tone, soft surfaces, generous spacing.
  • Clear — a strict type hierarchy makes complex feedback scannable.
  • Human — cutting-edge yet warm; approachable rounded shapes.

Design principles

  • Reduce cognitive load — less is more; strip non-essential decoration.
  • Legibility first — deep-slate text, never pure black; roomy line height.
  • Intentional white space — breathing room between sections.
  • Accessible by default — WCAG-AA contrast, visible focus, labeled inputs.
Depth through tone, not weight. Elevation is achieved with ambient shadows and tonal layers, and modals use backdrop blur rather than heavy overlays — keeping the interface light and transparent.

02 — Foundations

Logo

The RISE wordmark sits inside a soft, rounded container silhouette — a nod to a speech bubble and a rising card. It is the single most important brand asset and appears in the app header, auth screens, and this document.

Reversed — on primary surface

Usage rules

  • In-app the logo renders at 150px wide in the page header, 104px on auth screens, scaling down to 106–122px on small screens.
  • Keep clear space around the mark equal to the height of the container's corner radius; never crowd it with text or controls.
  • Do not recolor the wordmark into gradients, stretch it, rotate it, or add drop shadows. Use the near-black (#1d1d1b) mark on light, or the white reverse on primary.

07 — Library

Components

Live components reproduced from the production stylesheet. Every element here uses the same tokens the app ships with.

Buttons

Start interview Cancel Review Delete Submitting… Focus state

Primary = brand blue, white text, subtle shadow. Secondary = outlined neutral. Ghost = outlined, inverts to solid blue on hover. Danger = red text, fills red on hover. Focus = 2px #0056D2 ring at 2px offset. Minimum height 40px (44–48px for primary actions and touch targets). Disabled drops the fill and the elevation entirely — see Switched-off states.

Form fields

Labels are always visible (never placeholder-only). 44px min height, 1px outline; focus transitions to bright blue with a 3px soft glow.

Number input

Everything but the width comes from the shared field treatment — same 44px height, same 8px radius, same 1px outline, same 16px type, same focus ring. That is the whole rule: a number box is a field, and it is listed in the same selectors as every other field rather than given a parallel set of its own. A second definition of "what an input looks like" is a second thing to keep in step, and when it drifted the box came out square-cornered and 22px tall beside the fields around it.

It holds at most three digits and usually sits inline beside a label or a radio, so it is fixed at 84px instead of filling its container — full width would make a two-digit number look like a text field. tabular-nums keeps the digits from shifting as the value changes. Disabled is the ordinary disabled field: --surface-container fill, muted label, no fade. The fourth is a field whose blank would be visible to a reader — see the gap banner below.

Select field

The chevron is drawn, not native. A platform select arrow sits hard against the right edge and looks different on every operating system, so appearance: none removes it, 40px of right padding opens the room, and the chevron goes in as a background image.

This is the same rule the number input states, broken a second time and in the same way: the treatment was written as a hand-kept list of contexts, and every form added afterwards was left out of the list. Two settings forms and the statistics period picker all shipped with the raw native arrow jammed into the border. It is now one element-level rule for every select in the product.

It could only become element-level once every rule that styles a select used background-color rather than the background shorthand — the shorthand silently resets background-image, which is where the chevron lives. Do not reach for the shorthand on a field. That single character is what forced the per-context duplication in the first place.

A select and a date input each size themselves from their own internals, two and four pixels off a text input respectively. Invisible in a column, obvious in a row, so both are pinned to 44px.

Two bars stacked rather than side by side: the reader is comparing one competency with its own past, not with its neighbours. The lower bar turns red when it is shorter than the upper one, so a decline reads at a glance rather than needing the number.

The third row is the normal case, not an edge case. Any group below five students is withheld — these pages carry no names, but an average over two students read by their own teacher is not anonymous. A withheld row keeps its place and states its reason; a row that disappears becomes a zero in somebody's chart, which is a worse lie than saying nothing. The competency names are the school's own words from its own rubric, printed as written and never translated.

Every bar carries its number, above itself. The first version put the count in a title tooltip — invisible on a touch screen, unreadable at a glance on any screen, and the first question anyone asked of the chart was "how many is that one".

One colour. An earlier draft painted the last bar solid, inherited from a mockup where it was decoration; on a chart a different colour reads as a different kind of thing, and a reader is right to ask what it means. Bars are width-capped so four buckets do not stretch into four billboards.

Zero draws no ink. There is a minimum bar size so a small but real value stays visible; it applies only above zero. Applied blindly it drew a sliver of blue under a figure that said 0, and the picture disagreed with the number.

Granularity follows the window — per day up to ten days, per week up to a quarter, per month beyond — because thirty daily bars of single digits is a worse picture than four weekly ones, and a monthly chart over a week is one bar.

Period control

A retention period is a number and a unit, never a sentence. Typing "two years" into a text box would put those English words into the Serbian, French and Portuguese privacy notices, and nothing on screen would tell the person who typed it. The sentence is assembled per language at the point of display — which is also where Serbian gets its three plural forms (24 meseca, but 12 meseci).

Three states, not a number with a magic value: inherit, limit to n, and no limit. The store keeps 0 for "no limit", but nobody types it — the number box never accepts 0, which is what stops a zero meant as "none allowed" being read as its exact opposite. The box stays visible but disabled while another choice is selected, showing the value that would apply. The platform console renders the same control without the first row, because there is nothing above it to inherit from.

Settings rail

Settings outgrew one scrolling panel at four sections, and they do not fit in a tab row that already carries Users and Settings — nesting tabs inside tabs reads as two navigations arguing. The rail buys something a tab row cannot: a permanent place for each section to carry a status. "1 empty" is how an administrator learns the privacy notice is unfinished without opening it, and it is the only reason anyone would open that page a second time. The pip is red by default because the state it usually reports is an unfinished legal document, and green only when there is nothing left to report. Below 900px the rail lies down into a wrapping row.

Three destinations, numbered, and never one. A student cannot reliably classify their own problem, so the sheet does not ask them to — it lists all three with one line each and puts the school first, because that is who knows them. The separation is not tidiness: a single "contact us" address routes erasure requests into an IT inbox with a one-month statutory clock running and nobody there with authority to answer. An entry with no address is omitted entirely rather than shown empty — unlike the privacy notice, a help sheet with <email> in it is worse than one with two entries.

Status & meta chips

A status is a noun, in every language. The data-request table filled its status column from the action buttons, so it read "Mark answered" and "Refuse" — and a cancelled request showed the dismiss label of a modal, which in Serbian meant its status was the words "Not now". Verbs belong on buttons. A status names what a thing is, and needs its own string in each language rather than borrowing one that happens to be nearby.

A labelled aside for a consequence the reader must not skip — what an import just changed, why a scenario is retired. The label is the point: it says what kind of statement follows before the reader commits to the sentence. There is a warn variant in amber; it is for facts that carry a cost, never for emphasis. A note used to make ordinary text louder stops working the first time it matters.

Pills — settled, and waiting

u upotrebi Aktivan Pozvan Poziv istekao RETIRED

Two families, and the distinction is settled versus waiting, not severity. A neutral pill states a fact that needs nobody — a role, the content version in use, an active account. An amber pill marks something waiting on a person: an unaccepted invitation, an open erasure request, an organisation with no administrator. Amber here is not a warning about danger; it is a queue.

Field hint — including the disabled reason

Lozinka mora imati najmanje 10 znakova.

Napravi nalog

A disabled control must say why it is disabled. This is a rule the product learned the hard way: a registration form showed two filled-in password fields and an inert button, and the reader had no move at all. Whatever the cause — and in that case it was a browser autofill the page could not see — the state was indefensible. Name the unmet condition, in the reader's language, immediately below the control. The hint carries reasons, never decoration.

Data table on a phone

Every table cell carries a data-label, and below the table breakpoint each row becomes a card with those labels as its field names — so a phone shows a readable record instead of a grid scrolling sideways. This is why a new column is not finished until it has its label: without one it simply loses its name on mobile, silently, and only for the readers least able to work around it.

08 — Library

A school's own sentences in the privacy notice

Parts of the privacy notice can only be written by the school: who the controller is, who the data protection officer is, how long answers are kept. Those sentences are assembled from the school's settings, and how an unfinished one looks is a design decision, not a technical one.

To be completed by your school We keep your account for <period> after you stop using the platform.

The data controller is Tehnička škola Zrenjanin, Đorđa Stratimirovića 23, 23000 Zrenjanin. Our data protection officer is Milena Ristić, dpo@skola.example.

The box appears only while the sentence still has a blank in it. Once the school has filled it in, it is ordinary prose like every sentence around it.

The label used to be unconditional, and it leaked a build-time affordance into what a fifteen-year-old reads: a notice visibly assembled from parts, with one part disowned by the people who sent it. A filled sentence is not "to be completed by your school" — it is the school talking. The treatment is kept for a sentence that genuinely is unfinished, because a gap should look like a gap; it is the administrator, not the student, who is shown the count and told the notice does not yet satisfy Article 13.

Note the second sentence ends after the email address. A telephone is optional everywhere, and an optional field left blank must leave no trace — not a gap, and not a dangling comma before a full stop.

Switched-off states

Three different things get switched off, and they must not look alike. Through v1.0 the stylesheet had one rule for all of them — a blanket opacity: .62 — which is why a withdrawn scenario read as broken and a dead button could only be identified by pressing it.

Disabled

Cannot be used right now, and may become usable again. The affordance is removed on purpose, because acting on it is impossible — and it is removed by changing material, never by fading, so the state survives touch, daylight and greyscale.

All variants converge, deliberately. The ranking between primary, secondary and ghost is a ranking of the actions on offer; when none of them can be taken, the ranking has nothing left to say. Hover rules must be guarded with :not(:disabled) — unguarded, a disabled ghost still inverts to solid blue under the pointer and contradicts its own state.

Disabled and read-only fields

A disabled select also drops its chevron: a control that cannot open must not advertise that it opens. Note that :read-only matches disabled inputs too, so read-only rules need :not(:disabled) or they quietly undo the disabled fill.

Search, sector and level narrow it; the count above the table says what the filters left, against the whole catalogue.

Resume comes first, above the catalogue, because a student returning to an unfinished interview is the commonest reason this page is opened — and it names the question they stopped on rather than a percentage. An attempt left for two weeks or more is muted: still offered, no longer suggested.

Attempts and best score sit under the occupation name, and the primary action counts up — Započnite 3. pokušaj — so a student can see they are repeating rather than starting. On phones each row becomes a card, with the column names carried by data-label. This screen replaced a grid of scenario cards grouped under profession headings; that layout worked at 12 scenarios and stopped working at 224.

The dialogue counts what it destroys. “Are you sure?” invites a reflexive yes; “this removes 4 interviews and 38 answers” does not. The counts are real, fetched for this person at the moment of asking. Note what the dialogue does not contain: any of the content it is about to delete — an administrator can carry out an erasure without ever reading what is being erased. The keep option is worded as an action rather than as Cancel, so the safe choice reads as a choice.

Two buttons that look alike and are not. The copy downloads immediately — nobody approves it, and no member of staff opens a transcript in order to hand it over. 11 — Expression

Motion — Skill Constellation

While the AI evaluates an answer, RISE shows the Skill Constellation: a small network of nodes with energy pulsing along its edges and a traveling glow. It signals "your skills are connecting" — turning unavoidable model latency into a calm, on-brand moment instead of a spinner.

Timing. Energy flows on a 1.8s loop, nodes pulse on 1.6s, and a glow travels the path on 2.4s — staggered so the network feels alive, not mechanical. UI transitions elsewhere are a quick 140ms ease.
Reduced motion. Under prefers-reduced-motion all animation stops and the constellation simply holds visible — respecting user and accessibility settings.

12 — Quality

Accessibility

The pilot explicitly includes students with special educational needs, so accessibility is a first-class requirement, not a polish pass. The baseline below is already in the system; the Launch-Preparation phase extends it (see the platform PRD, §7.2).

In the system today

  • Visible keyboard focus ring on every interactive element (2px #0056D2, 2px offset).
  • Labels always visible on inputs — never placeholder-only.
  • WCAG-AA text contrast across primary, body, and status colors.
  • Touch targets 44–48px for primary actions and the avatar control.
  • prefers-reduced-motion honored for the constellation.
  • Fluid layouts down to 320px; no loss of function on small screens.

Extended at Launch Prep

  • Localised login (falls back via browser language) so non-English readers can sign in.
  • aria-live announcements when AI feedback arrives.
  • Accessibility panel: OpenDyslexic font, 100/125/150% text scaling, high-contrast theme, text-to-speech.
  • Automated axe-core checks wired into the build.
  • All touch targets raised to a 44px minimum.

13 — Quality

Responsive Behaviour

The layout is fluid from 320px up to the 1280px cap. Three breakpoints progressively simplify structure — reflowing card grids, stacking form controls, and collapsing data tables into cards.
